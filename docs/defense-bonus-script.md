# 加分项答辩速讲稿

如果老师问“这个项目除了基本要求，还有什么亮点”，可以直接按下面顺序讲：

## 30 秒版本

“这个项目的加分点主要有三类。第一，它不是静态分析，而是完整可交互的 Web 系统；第二，它不是只跑一个模型，而是做了三模型对比、KNN 调参和特征解释；第三，它不只用模拟数据，还额外整理了 UCI 的真实公开医疗数据做跨源验证，所以整体更像一个完整的 AI 应用系统，而不是单次实验。”

## 1 分钟版本

“我觉得这个项目比较有加分竞争力的地方，一是展示形式，我们做成了可交互系统，老师可以现场录入、修改、查看趋势和智能建议。二是模型部分不是单模型结果，而是用了 Logistic Regression、KNN 和 Gaussian Naive Bayes 三种模型做对比，并且对 KNN 额外做了参数扫描。三是数据部分不只停留在模拟样本，还整理了 UCI Cleveland Heart Disease 公开数据，做了缺失值处理和跨源验证。最后，报告里也不是只写好结果，还写了局限性和后续改进方向，所以从完整性和专业性上会更强一些。”

## 如果老师追问“最能体现专业度的是哪一点”

可以直接回答：

“最能体现专业度的是双数据链路。主任务用生活方式数据完成风险建模，外部再用 UCI 真实公开医疗数据验证同一处理流程能不能迁移，这样项目就不只是一个只在本地样本上成立的演示。”

## 如果老师追问“最能体现工程能力的是哪一点”

可以直接回答：

“最能体现工程能力的是把分析、模型、界面和智能建议接成了一个可运行系统。用户改动数据后，画像、趋势和建议会联动变化，这比只交一份报告更能体现系统实现能力。”
