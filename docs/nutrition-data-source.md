# 营养数据来源说明

当前应用中的“智能营养估算”功能使用了本地内置的食材营养参考库，数据文件位于：

- `backend/src/main/resources/seed/food_nutrition_reference.json`

整理原则：

- 参考 `USDA FoodData Central` 公开营养标准，选取常见蔬菜、菌菇、豆制品、主食与基础蛋白食材。
- 统一换算为“每 100 g 营养值”，便于前端按用户输入克数进行线性估算。
- 对用户常见输入补充了中文别名与英文别名，例如“番茄 / 西红柿”“卷心菜 / 包菜 / 甘蓝”。

当前系统实现：

- 支持食材搜索与候选推荐。
- 支持单食材估算。
- 对“番茄炒蛋”“香菇豆腐”等组合名称，支持按主要食材与次要食材做快速组合估算。

说明：

- 这是面向健康记录场景的快速估算库，不替代专业营养软件的精确称重分析。
- 如果后续需要公网长期部署并持续扩充，可以继续接入 `USDA FoodData Central API` 或中国食物成分表数据源做在线更新。
