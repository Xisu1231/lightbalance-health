# 人工智能课程大作业报告骨架

## 1. 项目名称

基于生活方式数据的健康风险分析与智能建议系统

## 2. 项目背景与问题描述

- 背景：很多健康管理软件只记录数据，不解释趋势，也缺少面向当天状态的行动建议。
- 问题：能否基于生活方式数据，判断用户是否处于较高健康风险，并给出饮食、训练、恢复方面的个性化提示。
- 任务类型：二分类任务（高风险 / 低风险）+ 数据分析展示。

## 3. 数据来源与数据说明

- 数据来源：自建模拟数据集
- 数据规模：320 条样本
- 字段：
  - BMI
  - 睡眠时长
  - 日步数
  - 运动时长
  - 饮水量
  - 热量摄入
  - 蛋白质摄入
  - 压力评分
  - 静息心率
  - 腰围
  - 屏幕时长
  - 是否吸烟
  - 是否深夜加餐
  - 风险标签

## 4. 数据预处理

- 读取 CSV 数据
- 检查字段完整性
- 数值特征标准化
- 训练集 / 测试集按 8:2 划分

## 6. 模型选择与实现

- 模型一：逻辑回归
- 模型二：KNN（k=7）
- 选择原因：
  - 逻辑回归适合二分类且解释性较强
  - KNN 适合作为对比模型观察局部邻域分类效果

## 7. 模型评价结果

- 评价指标：
  - Accuracy
  - Precision
  - Recall
  - F1
- 当前结果：
  - Logistic Regression：Accuracy 95.31%
  - KNN：见系统分析界面与 `model_report.json`

## 8. 结果分析

- 睡眠不足、步数偏低、压力偏高与高风险标签关系明显
- 逻辑回归在本数据集上更稳定
- KNN 在边界样本上更容易受邻近样本波动影响

## 9. 项目展示方式

- 软件形式：Vue + Spring Boot 的前后端分离桌面风格 Web 应用
- 主要模块：
  - 今日概览
  - 身体画像
  - 饮食规划
  - 训练计划
  - 追踪趋势
  - 智能建议

## 10. 总结与改进方向

- 当前数据仍为模拟数据
- 后续可接入真实手环或体脂秤数据
- 可继续引入随机森林、XGBoost 等模型进行比较
- 可增加用户登录、多用户档案、历史周报导出
